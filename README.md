# Finance Assistant

Учебный проект: ассистент, который отвечает на вопросы по финансовой отчётности и указывает страницы с источниками. Основа для оценки - [FinanceBench](https://github.com/patronus-ai/financebench).

## Первый этап

Взять один PDF из FinanceBench, извлечь текст по страницам и вручную проверить качество извлечения. Поиск и вызовы LLM добавим после этого.

Критерий готовности: для каждой страницы сохранены имя документа, номер страницы (начиная с 1) и текст; проверены несколько страниц с текстом и таблицами. Номер страницы PDF может отличаться от напечатанного номера. В исходной разметке FinanceBench страницы нумеруются с 0 — это нужно учитывать при сопоставлении.

## Окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
python --version
```

## Структура

- `src/finance_assistant/` — код приложения.
- `data/raw/` — исходные PDF и данные бенчмарка.
- `data/processed/` — извлечённый текст и поисковый индекс.
- `reports/` — результаты оценки и разбор ошибок.
